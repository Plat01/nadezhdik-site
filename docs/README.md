## Как страницы попали в репозиторий

`npm run export:tilda` (`scripts/tilda_export.py`) вызывает `getprojectexport`, `getpageslist` и `getpagefullexport`,
скачивает CSS/JS/картинки/шрифты в `public/tilda/`, переписывает ссылки на локальные, убирает статистику Tilda и
раскладывает страницы по адресам: главная → `public/index.html`, остальные → `public/<алиас>/index.html`.
Актуальный список страниц с ID — `docs/tilda-pages.json`. Старый адрес главной `/2` отдаёт 301 на `/` (nginx).

Официальный API документирует только GET-запросы на чтение и экспорт: изменить что-то в самой Tilda из
репозитория нельзя, и правки в `public/` в Tilda не попадают. После переключения домена на свой сервер Tilda
больше не используется.

## Ключи и ограничения

- Ключи читаются из локального `.env` (`PUB_KEY`, `SECRET_KEY`). Значения не записаны в документацию. `.gitignore` исключает `.env` и его варианты из Git; шаблон — `.env.example`.
- API ограничен **150 запросами в час**. Tilda предназначает его для синхронизации после изменений, а не для запроса при каждом посещении сайта.
- При размещении экспортированных через API страниц на своём сервере Tilda требует отметку «Made on Tilda» со ссылкой на `https://tilda.cc` на каждой странице.
- Если секретный ключ попадал в публичный репозиторий или журнал, перевыпустите его в настройках Tilda и обновите локальный `.env`.
