## Что можно делать вместе со мной

**С текущими API-ключами:** получать список проектов и страниц, сведения о них, HTML опубликованных страниц и набор ресурсов для экспорта. По этим данным я могу провести аудит текста, структуры, SEO и доступности, подготовить правки, CSS/JavaScript, фрагменты HTML и локальную копию или интеграцию сайта на отдельном сервере. Для экспорта и синхронизации доступны методы `getpage`, `getpagefull`, `getpageexport`, `getpagefullexport`.

**Через редактор Tilda при доступной авторизованной сессии:** менять текст, изображения, блоки, настройки страниц и затем публиковать страницы. Способ внесения конкретной правки зависит от блока и состояния входа в аккаунт. Подготовленный мной код можно поместить, например, в блок T123 или настройки HTML страницы/сайта. После изменения опубликованной страницы её требуется опубликовать повторно, чтобы посетители увидели новую версию.

**Граница API:** официальный API документирует только GET-запросы на чтение и экспорт. Он не предоставляет методов для изменения блоков, страниц, настроек проекта или публикации. Правка локально выгруженного HTML сама по себе не меняет сайт в Tilda. Ключи не заменяют вход в редактор.

## Как начать работу над правкой

1. Укажите страницу по названию или ID и опишите изменение.
2. Я получу актуальное содержимое, предложу или подготовлю правку и проверю её, где это возможно.
3. Для изменения самого сайта нужна авторизованная сессия редактора Tilda. Результат публикации проверяется отдельно на публичном сайте.

Примеры запросов: «Проверь SEO страницы English», «Подготовь новый текст для блока на главной», «Измени заголовок страницы Dance в редакторе Tilda», «Выгрузи опубликованные страницы в этот репозиторий».

## Ключи и ограничения

- Ключи читаются из локального `.env` (`PUB_KEY`, `SECRET_KEY`). Значения не записаны в документацию. `.gitignore` исключает `.env` и его варианты из Git; шаблон — `.env.example`.
- API ограничен **150 запросами в час**. Tilda предназначает его для синхронизации после изменений, а не для запроса при каждом посещении сайта.
- При размещении экспортированных через API страниц на своём сервере Tilda требует отметку «Made on Tilda» со ссылкой на `https://tilda.cc` на каждой странице.
- Если секретный ключ попадал в публичный репозиторий или журнал, перевыпустите его в настройках Tilda и обновите локальный `.env`.
