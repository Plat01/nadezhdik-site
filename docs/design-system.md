# Дизайн-система «Надеждика»

Снята со страниц Tilda (главная, School). Живая витрина всех элементов — `/styleguide` (`npm run dev` →
http://localhost:4321/styleguide/). Код: `src/styles/tokens.css`, `src/components/`.

## Характер

Яркий, «плакатный», детский, но не сюсюкающий. Узкий жирный Impact капсом на наклонных плашках, похожих на
стикеры и речевые пузыри; крупные плоские цветовые поля; маскот-пингвин Надеждик. Текст — Montserrat Alternates,
мягкий и округлый. Никаких теней, градиентов и скруглённых карточек — только плоские плашки и прямые углы.

## Токены

| Группа | Токены | Где используются |
|---|---|---|
| Цвета | `--c-orange` #ff532c, `--c-blue` #0091cf, `--c-cream` #e1e1c2, `--c-ink` #2a2a2b | фоны секций, текст, плашки |
| Доп. цвета | `--c-orange-soft`, `--c-navy`, `--c-yellow`, `--c-yellow-deep`, `--c-black` | редкие акценты, иконки |
| English N club | `--c-red` #c22127, `--c-white`, фон `--c-navy` | только лендинг `/english/` |
| Шрифты | `--font-display` (Impact), `--font-text` (Montserrat Alternates 500), `--font-accent` (Sigmar, только латиница) | заголовки и кнопки / текст / надписи English N club |
| Кегли | `--fs-hero` 86, `--fs-h1` 52, `--fs-h2` 36, `--fs-h3` 31, `--fs-h4` 22, `--fs-lead` 20, `--fs-body` 16, `--fs-small` 14 | значения для десктопа, на мобильных меньше через `clamp` |
| Отступы | `--space-1…6` (8, 16, 24, 40, 60, 60–120), `--gutter` 20, `--container` 1160, `--container-wide` 1360 (`.container--wide`) | широкий — для лендингов по макетам 1900 |
| Приёмы | `--tilt` −4°, `--tilt-strong` −8°, `--rule` (линия-разделитель) | наклон плашек и кнопок |

Основной текст — кремовый на цветном фоне. Тёмный текст (`--c-ink`) — на кремовых плашках и как второй
заголовок в карточках. Фон страницы по умолчанию голубой.

## Компоненты

| Компонент | Назначение |
|---|---|
| `Base` (layout) | `<head>`, SEO/OG, Метрика, шапка и подвал |
| `Header` | маскот → главная, VK, Telegram, телефон, бургер-меню (`nav` из `src/data/site.ts`); `tone="navy"` + `logo` + `wide` — шапка лендинга направления (свой логотип, красные телефон и бургер). VK, Telegram, телефон и бургер стоят по координатам Zero Block главной (и так же масштабируются ниже 960), чтобы не прыгать при переходе со старых страниц — не двигать их на отдельных страницах |
| `Footer` | оранжевое полотно с надписью НАДЕЖДИК и хвостиком пузыря, голубая полоса: © / маскот / телефон; `variant="short"` — только голубая полоса с косым верхом на тёмно-синем |
| `Section` | полноширинная секция: `tone` orange/blue/ink/cream, `pad` none/sm/md/lg |
| `Heading` | заголовок Impact: `as` (тег), `size` (hero…h4), `upper`, `align`, `tone` |
| `Sticker` | наклонная плашка: `bg`, `color`, `accent` (для `<span class="accent">`), `size`, `tilt`, `tail` |
| `Button` | `sticker` (тёмная наклонная, «УЗНАТЬ БОЛЬШЕ»), `solid`, `outline`; ссылка при `href` |
| `Card` | фото 1:1, заголовок, подзаголовок, линия, текст, кнопка |
| `Grid` | сетка карточек 1 → 2 (640+) → 3/4 (960+) колонки |
| `FeatureList` | тёмный список преимуществ с оранжевыми точками, 2 колонки с 960 |
| `DocLink` | ссылка-папка на документ |
| `LeadForm` | **временная** форма заявки → `/api/lead` |

## Шаблоны секций (порядок как на главной)

1. **Hero** — оранжевый/голубой фон, стикеры «Привет» + «Я Надеждик» с хвостиками, полосы-плашки с
   ключевым сообщением, маскот справа (снизу на мобильных).
2. **Направления** — голубой фон, `Grid cols={2}` из `Card`.
3. **Лента-заголовок** — оранжевая полоса `pad="sm"` с одним заголовком капсом по центру.
4. **Преимущества** — `Section tone="ink"` + `FeatureList`.
5. **Документы** — оранжевый фон, заголовок капсом, `DocLink`.
6. **Вопрос/заявка** — оранжевый фон, `LeadForm`, сразу перед подвалом.

## Брейкпоинты

Как у Zero Block: 480, 640, 960, 1200. Вёрстка mobile-first (`min-width`). Проверка — `npm run check:visual`
на всех пяти ширинах, обязательно без горизонтального скролла на 320.

## Ресурсы

`public/brand/` — логотип-знак (favicon), маскот, надпись НАДЕЖДИК, иконки VK/Telegram, папка, плашка
Noisy Brands. `public/fonts/` — Impact и Montserrat Alternates (woff). Фото направлений пока лежат в
`public/tilda/img/` (ресурсы старых страниц); для новых страниц — копировать в `public/images/<slug>/`.
