# Выгрузка из Tilda

После миграции источник правды — репозиторий. Повторная выгрузка **затирает** локальные правки в HTML старых
страниц, поэтому:

1. Проверь `git status` и `git log -- public/*.html public/*/index.html`: были ли локальные правки старых страниц.
   Если были — предупреди пользователя и выгружай только нужную страницу (`--page <ID>`), затем перенеси правки
   заново (или через `git diff`).
2. ID страниц — в `docs/tilda-pages.json`. Ключи `PUB_KEY`/`SECRET_KEY` — в `.env`. Лимит API — 150 запросов/час
   (полная выгрузка ≈ 7).
3. Запуск: `npm run export:tilda -- --force [--page <ID>]`. Скрипт скачивает ресурсы в `public/tilda/`,
   переписывает ссылки на локальные, убирает статистику Tilda, подключает `legacy-overrides.css`.
4. Проверка: `npm run build`, preview, `npm run check:visual -- <путь> --ref https://nadezhdik.ru<путь>` —
   diff около 0%, в выводе нет «Запросы к Tilda». Если скрипт сообщил об оставшихся ссылках на tildacdn —
   разберись и доработай `scripts/tilda_export.py`.
5. Новая страница в Tilda → добавь её адрес в `legacyPages` (`astro.config.mjs`) и, если нужно, в `nav`.
