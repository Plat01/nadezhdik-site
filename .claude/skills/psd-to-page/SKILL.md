# Страница по PSD-макету

1. **Разбор макета.** Файл должен лежать в `design/mockups/` (папка в `.gitignore`). Запусти
   `npm run psd -- design/mockups/<имя>.psd`. Прочитай `design/specs/<имя>/spec.md` (тексты, шрифты, кегли, цвета
   → токены) и посмотри `preview.png` (при большой высоте — по частям). `spec.json` — для точных координат.
   Если макетов несколько (desktop/mobile) — разбери каждый.
2. **Сопоставление с дизайн-системой.**
   - Цвета: берём токен из таблицы `spec.md`; Δ > 20 — новый цвет, спроси пользователя или добавь токен.
   - Шрифты: Impact → `--font-display`, Montserrat Alternates → `--font-text`. Другой шрифт — спроси, прежде чем
     подключать (файл шрифта нужен в `public/fonts/`).
   - Кегли: ближайший `--fs-*`; если макет последовательно расходится — поправь шкалу в `tokens.css`, а не локально.
   - Повторяющиеся элементы — существующие компоненты; новый элемент — новый компонент (+ пример на `/styleguide`).
3. **Картинки.** Нужные слои из `design/specs/<имя>/layers/` скопируй в `public/images/<slug>/` с понятными
   именами (фото → `.jpg`/`.webp`, иллюстрации с прозрачностью → `.png`/`.webp`, не шире 1600px).
4. **Вёрстка** — по правилам `CLAUDE.md`: `src/pages/<slug>.astro`, flex/grid, mobile-first. Макет задаёт
   десктоп; мобильные версии без макета — по образцу секций `/styleguide`.
5. **Сверка.** `npm run build`, preview, затем
   `npm run check:visual -- /<slug>/ --ref design/specs/<имя>/preview.png --name <slug>-psd`
   (снимок делается на ширине макета). Смотри `*-diff.png`: ищи сдвиги блоков, другие кегли, отступы.
   Итерации, пока расхождения не сведутся к сглаживанию шрифтов и фото; затем прогон без `--ref` на всех 5
   ширинах для адаптива.
6. **Отчёт:** что сверстано, итоговый diff %, отличия от макета, которые оставлены сознательно (и почему).
