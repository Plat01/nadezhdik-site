# Новая страница без макета

1. **Бриф.** Выясни из запроса: адрес (`/slug/`), заголовок, цель страницы, блоки и тексты, картинки, нужна ли форма
   заявки, нужна ли страница в меню. Если текстов нет — напиши черновые в тоне сайта (коротко, дружелюбно, для
   родителей) и явно пометь это в ответе.
2. **Шаблоны.** Открой `src/pages/styleguide.astro` и `docs/design-system.md`: собери страницу из готовых секций
   (hero со стикерами, сетка карточек, лента-заголовок, преимущества, документы, форма). Чередуй фоны секций
   (orange / blue / ink), как на главной.
3. **Страница.** Создай `src/pages/<slug>.astro` на `Base` с `title` и `description`. Только компоненты и токены,
   никаких классов Tilda и «магических» значений (правила — в `CLAUDE.md`). Если нужен новый компонент —
   положи его в `src/components/`, добавь пример на `/styleguide` и строку в `docs/design-system.md`.
4. **Картинки** — в `public/images/<slug>/`, большие растровые — не шире 1600px, `alt` на русском.
5. **Меню/SEO.** При необходимости добавь пункт в `nav` (`src/data/site.ts`). Если на этом адресе была страница
   Tilda (`public/<slug>/index.html`, например пустые `dance`/`football`) — удали её и убери адрес из `legacyPages`
   в `astro.config.mjs`, если он там есть: новую страницу Astro сам добавит в sitemap.
6. **Проверка.** `npm run build`, запусти preview, затем `npm run check:visual -- /<slug>/`. Просмотри скриншоты
   всех 5 ширин (`reports/visual/<slug>/`): нет горизонтального скролла, тексты не налезают, стикеры не обрезаны.
   Исправь и повтори.
7. Коротко отчитайся: адрес, из каких секций собрано, что осталось заменить (черновые тексты, заглушки картинок).
