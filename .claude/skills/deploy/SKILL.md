# Деплой

1. **Перед пушем:** `npm run build` без ошибок; для изменённых страниц — `npm run check:visual` и просмотр
   скриншотов. `git status` — в коммит не попадают `.env`, `design/`, `reports/`.
2. **Коммит и push.** Изменения — через ветку и PR (`gh pr create`), либо прямо в `main`, если пользователь так
   просит. Деплой запускается push'ем в `main` (`.github/workflows/deploy.yml`).
3. **Наблюдение:** `gh run watch` / `gh run view --log-failed`. Если job `deploy` пропущен — не задана
   переменная `DEPLOY_HOST`: сайт только собран, см. `docs/deploy.md`.
4. **Проверка живого сайта** (адрес — переменная `SITE_URL`, после переключения DNS — https://nadezhdik.ru):
   `curl -I <SITE_URL>/`, `curl <SITE_URL>/api/health`, затем
   `npm run check:visual -- <SITE_URL><путь>` для изменённых страниц.
5. Отчитайся: что выкачено (коммит), результат workflow, результат проверок. Откат — `git revert` + push.

Первичная настройка сервера и переключение DNS — только вместе с пользователем по `docs/deploy.md`
(это действия с внешними системами, требуют его подтверждения).
